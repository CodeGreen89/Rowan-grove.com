# Contracting site archive

This folder preserves the complete Rowan Grove contracting-focused website that was live immediately before the small-business IT redesign.

Its headline is:

> Senior cloud engineering, without the full-time overhead.

The archive contains the original HTML, images, search metadata, and Azure Static Web Apps configuration. To preview it locally, serve this folder with any static HTTP server. It can later be restored as the main site or published as a separate route or site.
